## 🌟 Executive Overview
**Estate Matrix** is a production-ready, ultra-modern luxury real estate showcase and high-intent lead generation engine built specifically for luxury property brokers, ultra-HNI family offices, real estate developers, and international channel partners operating across **Mumbai, Dubai, Bangalore, and Goa**.

Engineered with dark obsidian luxury aesthetics, gold-champagne accents, interactive architectural blueprint viewers, live mortgage amortization calculators, VIP chauffeur viewing schedulers, and direct WhatsApp deal-closing funnels.

## 🚀 Quick Start / Local Deployment

Estate Matrix runs natively in any modern web browser with zero build steps or heavy node dependencies required.

### 1. Simple Python Local Server
```bash
cd /home/shreeleela/estate-matrix/
python3 -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

### 2. Deploy to Production (Vercel / Netlify / GitHub Pages / Cloudflare Pages)
Simply push this repository to GitHub/GitLab and link it to **Vercel** or **Cloudflare Pages** for instant sub-second global edge delivery with SSL.

## 🛠️ Customization & Configuration Guide

### 1. Updating WhatsApp Numbers
Open [`js/app.js`](js/app.js) and update the WhatsApp phone number in:
```javascript
// Replace 919820012345 with your broker WhatsApp number (with country code)
const waNumber = "919820012345";
```

### 2. Adding / Modifying Properties
Open [`js/data.js`](js/data.js) and add new property entries to `LUXURY_PROPERTIES`:
```javascript
{
  id: "prop-custom-01",
  title: "Worli Bay Horizon",
  locationKey: "mumbai", // 'mumbai', 'dubai', 'bangalore', 'goa'
  propertyType: "penthouses", // 'penthouses', 'seafront-villas', 'high-rise-condos'
  priceINR: 280000000, // ₹28 Cr
  carpetAreaSqFt: 6200,
  bedrooms: 4,
  facing: "Arabian Sea (West)",
  status: "Ready to Move",
  heroImage: "https://...",
  ...
}
```
